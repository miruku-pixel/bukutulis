# Sasando Project

A modern Next.js application featuring a two-step authentication form with smooth animations and secure server actions.

## Getting Started

1. Clone the repository.
2. Create a `.env.local` file based on `.env.example`.
3. Set your `AUTH_BASE_URL` in `.env.local`.
4. Run the development server:
   ```bash
   npm install
   npm run dev
   ```

## Key Features
- **Two-Step Auth**: Get token first, then login.
- **Modern UI**: Built with Shadcn UI and Tailwind CSS.
- **Animations**: Granular slide and fade effects using CSS transitions.
- **Server Actions**: Secure backend-only authentication handling.
