# BukuTulis Project

A modern Next.js application featuring a backend-driven authentication flow with smooth animations and secure server actions.


## Key Features
- **Backend-Driven Auth**: Combined token generation and user login.
- **Modern UI**: Built with Shadcn UI and Tailwind CSS.
- **Animations**: Granular slide and fade effects using CSS transitions.
- **Server Actions**: Secure backend-only authentication handling.
